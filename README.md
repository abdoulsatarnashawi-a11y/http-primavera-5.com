# Primavera-5 | Авточасти и аксесоари

Онлайн магазин за авточасти, аксесоари и оборудване за всички марки и модели автомобили.

**Домейн:** [primavera-5.com](http://primavera-5.com)

## Характеристики

- Пълен динамичен електронен магазин на български език
- Цени в евро (€) — видими само за регистрирани потребители
- Цена на дребно и цена на едро за всеки продукт
- Регистрация и вход за клиенти
- Админ панел за управление на продукти, поръчки и настройки
- Редактируем хедър и футър от админ панела
- Проследяване на посетители във футъра
- Страници: Контакти, Поверителност, Общи условия, Бисквитки и съгласие, Законна информация, Право на отказ
- Банер за бисквитки (GDPR/ePrivacy) и съгласие при регистрация и поръчка

## Стартиране

```bash
npm install
npx prisma db push
npm run db:seed
npm run dev
```

Отворете [http://localhost:3000](http://localhost:3000)
